# mengsanguo-bot
梦三国2巅峰争霸脚本

## 5.6 源码

本软件永久免费，为爱发电，请勿用于商业用途。请设置游戏界面风格为经典画面。

这是 5.6 版本源码，不含个人录像、操作采集、战绩、学习数据和运行日志。保留 4.9 的一键更新功能。

### 5.6 的实战优化

- 小地图仅用于瞬时查看和下达指令。
- 地图移动后立即双按 F1 回到英雄自身视角。
- 传送指令发出后立即恢复自身视角，不再停留在远处空地。
- 保持对英雄身边敌人、血量和施法时机的持续观察。

详细数据见 [5.6 实战优化说明](5.6实战优化说明.md)。

### 5.5 的实战优化

- 撤销 5.4 中造成战绩退化的强制团战驻留。
- 不再反复向同一危险交战中心补发移动指令。
- 恢复 5.3 已验证的跟团、转场和传送节奏。
- 保留“有队友低血继续战斗、落单低血才撤退”的规则。

详细数据见 [5.5 实战优化说明](5.5实战优化说明.md)。

### 5.4 的实战优化

- 团战跟随命令持续生效，不被传送或闪动目标过早覆盖。
- 友方团战点短暂丢失时保留 18 秒记忆。
- 对稳定团战点定期重新发送靠拢指令，减少途中被打断后落单。
- 跟团刷新更快，优先稳定参团、助攻和生存。

详细数据见 [5.4 实战优化说明](5.4实战优化说明.md)。

### 5.3 的实战优化

- 低血量撤退只在附近没有队友时触发。
- 团战中即使低血量也继续战斗。
- 撤退过程中重新遇到队友会立刻解除撤退锁。

详细数据见 [5.3 实战优化说明](5.3实战优化说明.md)。

### 5.2 的实战优化

- 根据 2026-10-18 三组 5.1 肉盾挂机数据与关键画面，修正残血撤退方向。
- 低血时优先返回己方基地；基地无法可靠确认时，选择敌方红点最少的友军安全区，不再冲向友军交战热点。
- 撤退指令间隔调整为 8 秒，最短撤退锁延长到 10 秒；仍需血量连续恢复到 55% 以上才重新战斗。
- 每次低血撤退阶段最多自动使用两个带数量物品，避免长时间残血快速耗尽背包。
- 死亡后必须检测到血量至少 40% 并连续确认三次，才恢复战斗逻辑。

详细数据与限制见 [5.2 实战优化说明](5.2实战优化说明.md)。

### 5.0 的小范围战斗修正

- 卡包入口必须同时满足数字和两侧边框结构，排除自动购买文字、价格及装备图标下方数字。
- 连续无敌情至少 6 秒、近期未交战且非低血时才尝试开卡；跟团移动期间暂缓翻卡。已打开但尚未翻开的面板遇敌或低血时优先关闭。
- 施法后单按 F1 重新选中自身，设置约 0.65 秒的指令保护，减少新追击指令打断施法；不把这一机制等同于识别技能冷却或引导时间。
- 从左上角固定自身血条读取绿/黄/红血量。可读血量低于约 25% 且遇敌时尝试撤向低敌情友方候选区或己方基地，不再把最激烈的交战区当成撤退点。不是路径安全保证。
- 保留开局天赋、商店两次确认、技能键位/节奏、战绩 1500 停卡和个人学习数据。

依据两组 2026-10-17 挂机数据的日志与关键画面抽样修正；不是完整逐帧人工观看，也没有把挂机录制当作人工优秀样本学习。64 次历史开卡尝试中有 17 次点击位置位于实际卡包区域下方，离线回放均不再产生区域外候选，同时保留实测真卡包。离线检查不代表实战胜率或助攻已提高，需继续录制对比。

### 运行

需要 Windows、Python 3.11 或更新版本。在仓库根目录打开 PowerShell：

```powershell
Copy-Item config.example.json config.json
python -m pip install -r source/requirements.txt
python source/main.py
```

请先复制示例配置，再按自己的快捷键修改。自动操作适配 1024×768 游戏客户区；录制选项不代表自动操作支持其他分辨率。游戏需保持前台，F8 启动或暂停，F9 停止。

### 打包

```powershell
powershell -ExecutionPolicy Bypass -File source/build.ps1
```

生成程序需与 `config.json`、`templates/`、`assets/` 保持在同一目录。
英雄名识别使用可选的 Tesseract OCR；未安装时自动识别可能不可用。
详细功能见 [使用说明](使用说明.md)。离线检查不能替代实战验证，不保证战绩或收益；请自行遵守游戏服务条款。

## 一键更新与发布

首次从 4.8 升级到 4.9 仍需手动安装一次，4.9 起可在软件内更新。
仅下载本仓库最新正式 Release 中的 `MengSanGuoBot-update.zip`；源码提交、草稿或预发布不会触发更新。下载要求 GitHub 返回 SHA256 摘要，缺少或不一致时拒绝安装。

发布者每次修改 `source/main.py` 的 `APP_VERSION`，打包后执行：

```powershell
python source/package_release.py --version 5.6 --output release-output
```

在 GitHub 仓库 Releases 创建版本（例如标签 `v5.2`），上传生成的 `MengSanGuoBot-update.zip`、`MengSanGuoBot-5.2.zip` 和 `SHA256.txt`，填写说明并作为正式版本发布。后续版本使用相应版本号。请不要将 GitHub Token 写入软件。

安装前必须停止挂机、录制和分析。更新只替换程序、模板、背景图和示例配置，不覆盖个人配置、战绩、学习数据、OCR 安装或录像；新增配置项启动时补入内存，现有选项保留。替换失败尝试恢复，错误见 `update_error.txt`；成功后的旧文件备份位置见 `update_success.txt`。

关闭软件时正进行的下载可能中断，但未完成校验不会替换原程序。重启后需手动按 F8 启动挂机。
